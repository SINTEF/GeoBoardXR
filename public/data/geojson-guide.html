GeoJSON Data Guide

How to structure .geojson files for the VR Tabletop viewer.
Place any .geojson file in public/data/ — it will appear automatically as a toggle button.

File structure

Every file must be a valid GeoJSON FeatureCollection. A single file can mix Points, Polygons, and LineStrings freely.

// public/data/my-layer.geojson
{
  "type": "FeatureCollection",
  "name": "My Layer",   // optional — becomes the toggle button label
  "features": [
    // ... one or more Feature objects
  ]
}

The optional top-level "name" field becomes the toggle button label. If omitted, the filename (without .geojson) is used instead. Restart the dev server after adding a new file.

Point — pins & info markers

Renders as a vertical stick with a sphere head. Clicking a pin with information opens text (and optionally an image) on the projection walls. Only one pin can be selected at a time — the selected pin turns grayish-white while its info is displayed; clicking it again or selecting another pin restores its original colour.

ℹ️ Infopoint default colour: Pins that have an information property default to #23d110 (green) if no explicit color is set, so they stand out from plain yellow pins at a glance.

Geometry

{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [15.4147, 68.6944]   // [longitude, latitude]
  },
  "properties": { /* see table below */ }
}

Properties

PropertyTypeDefaultDescription
title optional string — Label displayed above the pin head.
color optional hex string #23d110 if information is set, #ffe600 otherwise Stick and head colour. Any CSS hex colour, e.g. "#ff4400". Infopoints turn grayish-white when selected.
information optional string — Body text shown on the projection walls when the pin is clicked. Enables the click interaction. Newlines (\n) are supported.
image optional string (URL or filename) — Image shown alongside the information text. Only valid when information is also set. Use a filename (e.g. "photo.jpg") for files placed next to the GeoJSON in public/data/, or a full URL for remote images.
3dmodel optional string (filename) — Filename of a .glb file placed in public/data/ (e.g. "tree.glb"). Replaces the default stick+sphere with the 3-D model, scaled to fit pin height automatically. A click target is still present for interaction.

Examples

// Simple labelled pin
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.42, 68.70] },
  "properties": {
    "title": "Measurement station",
    "color": "#00aaff"
  }
}

// Information pin with local image
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.39, 68.69] },
  "properties": {
    "title": "Research site",
    "color": "#ff5500",
    "information": "Water temperature: 8 °C\nDepth: 42 m",
    "image": "site_photo.jpg"
  }
}

// 3-D model pin
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.43, 68.71] },
  "properties": {
    "title": "Buoy",
    "3d_model": "https://example.com/models/buoy.glb",
    "information": "Oceanographic buoy #12"
  }
}

Polygon — areas & zones

Renders a flat filled area at terrain elevation. Supports plain colour, fire particle animation, and 3-D wave animation.

Geometry

{
  "type": "Feature",
  "geometry": {
    "type": "Polygon",
    "coordinates": [[     // outer ring — close it by repeating the first point
      [15.397, 68.687],
      [15.424, 68.688],
      [15.430, 68.700],
      [15.397, 68.687]   // same as first
    ]]
  },
  "properties": { /* see table below */ }
}
Only the exterior ring is rendered. Interior rings (holes) are currently ignored. Coordinate order is [longitude, latitude].

Properties

PropertyTypeDefaultDescription
title optional string — Billboard label shown above the polygon centroid.
color optional hex string #87cefb Fill colour when no animation is set. For wave, this also sets the water colour — use a blue tone. Ignored for fire.
opacity optional integer 0–100 70 Transparency of the polygon (plain colour only). 100 = fully opaque, 0 = fully transparent.
animation optional "fire" | "wave" — fire — dense particle effect covering the polygon footprint at terrain level. The flat polygon is hidden; particles are the entire visual.
wave — animated 3-D wave mesh (sine-wave vertex displacement). Use a blue color for a sea-water look. The flat polygon is hidden.

Examples

// Plain semi-transparent zone
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Protected area",
    "color": "#44cc88",
    "opacity": 50
  }
}

// Fire animation
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Fire zone",
    "animation": "fire"
  }
}

// Wave / water animation
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Fjord area",
    "color": "#005fad",
    "animation": "wave"
  }
}

LineString — routes, borders & walls

Renders as a ribbon following the terrain. Thin lines stay flat on the surface; tall lines automatically become vertical walls. A label appears at the midpoint.

Geometry

{
  "type": "Feature",
  "geometry": {
    "type": "LineString",
    "coordinates": [   // list of [longitude, latitude] pairs
      [15.388, 68.690],
      [15.405, 68.696],
      [15.445, 68.708]
    ]
  },
  "properties": { /* see table below */ }
}

Properties

PropertyTypeDefaultDescription
title optional string — Billboard label at the midpoint of the line.
color optional hex string #ff1a1a Ribbon colour.
linewidth optional number (metres) 3 Width of the ribbon in real-world metres. Used for both flat lines and the wall thickness.
lineheight optional number (metres) 5 Height of the ribbon in metres. When lineheight is more than 3× linewidth / 2, the ribbon is rendered as a vertical wall instead of a flat road-like surface. Use large values (e.g. 30–100) for fence/wall effects.

Examples

// Flat road-like route
{
  "type": "Feature",
  "geometry": { "type": "LineString", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Ferry route",
    "color": "#0044ff",
    "linewidth": 8
  }
}

// Vertical wall / fence
{
  "type": "Feature",
  "geometry": { "type": "LineString", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Zone boundary",
    "color": "#ff9900",
    "linewidth": 2,
    "lineheight": 40
  }
}

Complete example file

{
  "type": "FeatureCollection",
  "features": [

    // --- Point: info pin with photo
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [15.415, 68.694] },
      "properties": {
        "title": "Harbour",
        "color": "#00ccff",
        "information": "Main harbour.\nCapacity: 120 vessels.",
        "image": "harbour.jpg"
      }
    },

    // --- Polygon: fire hazard zone
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [[
          [15.397, 68.687], [15.424, 68.688],
          [15.430, 68.700], [15.397, 68.687]
        ]]
      },
      "properties": {
        "title": "Fire risk area",
        "animation": "fire"
      }
    },

    // --- Polygon: water body
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [[
          [15.440, 68.695], [15.470, 68.697],
          [15.465, 68.710], [15.440, 68.695]
        ]]
      },
      "properties": {
        "title": "Lake",
        "color": "#005fad",
        "animation": "wave"
      }
    },

    // --- LineString: patrol route
    {
      "type": "Feature",
      "geometry": {
        "type": "LineString",
        "coordinates": [
          [15.388, 68.690], [15.405, 68.696], [15.445, 68.708]
        ]
      },
      "properties": {
        "title": "Patrol route",
        "color": "#ff9900",
        "linewidth": 4,
        "lineheight": 6
      }
    }

  ]
}

Quick reference

PropertyApplies toType & values
title All Any string
color All Hex colour, e.g. "#ff4400"
information Point String — enables click interaction
image Point Filename or URL — requires information
3d_model Point URL to .glb / .gltf
opacity Polygon Integer 0–100 (default 70)
animation Polygon "fire" or "wave"
linewidth LineString Metres, default 3
lineheight LineString Metres, default 5. >3× half-width → vertical wall
