GeoJSON Data Guide

How to structure .geojson files for the VR Tabletop viewer.
Place any .geojson file in public/data/ — it will appear automatically as a toggle button.

File structure

Every file must be a valid GeoJSON FeatureCollection. A single file can mix Points, Polygons, and LineStrings freely.

// public/data/my-layer.geojson
{
  "type": "FeatureCollection",
  "name": "My Layer",   // optional — becomes the toggle button label
  "features": [
    // ... one or more Feature objects
  ]
}

The optional top-level "name" field becomes the toggle button label. If omitted, the filename (without .geojson) is used instead. Restart the dev server after adding a new file.

Playback file

A playback file is its own standalone .geojson file placed in public/data/ alongside any regular layer files. It gets its own toggle button in the VR menu — just like a normal layer — but with two extra circular buttons above it: ▶ / ⏸ to play/pause and ↺ to restart from the beginning. Regular layers and playback layers are independent; any number can coexist in the same session.

Add "playback": true at the top level of the file to enable this mode. All startTime / endTime values in the file are relative to the moment the user presses Play.

Any feature type — Point (pins), LineString, Polygon (including fire and wave polygon animations) — can carry startTime and/or endTime inside a playback file. The feature is hidden before playback starts, appears at startTime, and vanishes at endTime. For fire and wave polygons, the particles / wave also pause when the timing window closes. Features with no timing properties are always visible once the layer is toggled on. Playback-exclusive animations (move, justaudio, projection-photo, projection-video) only work in playback files.

{
  "type": "FeatureCollection",
  "name": "My Presentation",
  "playback": true,
  "features": [ /* ... */ ]
}

Point — pins & info markers

Renders as a vertical stick with a sphere head. Clicking a pin with information opens text (and optionally an image or video) on the projection walls. Only one pin can be selected at a time — the selected pin turns grayish-white while its info is displayed; clicking it again or selecting another pin restores its original colour.

ℹ️ Infopoint default colour: Pins that have an information property default to #23d110 (green) if no explicit color is set, so they stand out from plain yellow pins at a glance.

Geometry

{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [15.4147, 68.6944]   // [longitude, latitude]
  },
  "properties": { /* see table below */ }
}

Properties

PropertyTypeDefaultDescription
title optional string — Label displayed above the pin head.
color optional hex string #23d110 if information is set, #ffe600 otherwise Stick and head colour. Any CSS hex colour, e.g. "#ff4400". Infopoints turn grayish-white when selected.
information optional string — Body text shown on the projection walls when the pin is clicked. Enables the click interaction. Newlines (\n) are supported.
image optional string (URL or filename) — Image shown alongside the information text on two of the projection walls. Only valid when information is also set. Ignored if video is also set. Use a filename (e.g. "photo.jpg") for files in public/data/, or a full URL for remote images. Any browser-supported format works (JPG, PNG, WebP, GIF, SVG) — JPG or PNG preferred for best compatibility on all devices.
video optional string (filename) — MP4 video shown on two of the projection walls. Only valid when information is also set. Takes priority over image. Place the file in public/data/ and reference it by filename, e.g. "clip.mp4". A play button is shown when paused — shoot or click the wall to play; shoot again to pause. Selecting a different infopoint resets the video to the beginning.
3dmodel optional string (filename) — Filename of a .glb file placed in public/data/ (e.g. "tree.glb"). Replaces the default stick+sphere with the 3-D model, scaled to fit pin height automatically. A click target is still present — information, image, video, and color all work alongside it.
modelscale optional number (multiplier) 1 Scale multiplier applied on top of the automatic pin-height scaling. 2 = twice as large, 0.5 = half size. Only has effect when 3dmodel is set.
modelrotate optional number (degrees) 0 Rotates the 3-D model around the vertical axis, clockwise, compass-style. 0 = original model orientation, 90 = facing East, 180 = flipped, 270 = facing West. Only has effect when 3dmodel is set.

Examples

// Simple labelled pin
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.42, 68.70] },
  "properties": {
    "title": "Measurement station",
    "color": "#00aaff"
  }
}

// Information pin with local image
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.39, 68.69] },
  "properties": {
    "title": "Research site",
    "color": "#ff5500",
    "information": "Water temperature: 8 °C\nDepth: 42 m",
    "image": "site_photo.jpg"
  }
}

// Information pin with video
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.40, 68.71] },
  "properties": {
    "title": "Field recording",
    "color": "#0a5ade",
    "information": "Site survey footage from June 2026.",
    "video": "clip.mp4"
  }
}

}

Playback-only Point animations

These features use a Point geometry but their coordinates are ignored — place them anywhere valid (e.g. the centre of your map). They only activate inside a file with "playback": true. All share the same timing properties:

PropertyTypeDefaultDescription
startTime optional number (seconds) 0 Seconds after the user presses Play when the animation activates.
endTime optional number (seconds) — Seconds after Play when the animation stops. If omitted the animation runs until the source ends naturally.

animation: "justaudio"

Plays an audio file (narration, ambient sound, etc.) at the given time. Multiple justaudio features in the same file play independently and can overlap.

PropertyTypeDefaultDescription
audio required string (filename) — MP3/WAV/OGG file in public/data/.
audioVolume optional number 0.0–1.0 1.0 Playback volume. 
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.402, 68.693] },
  "properties": {
    "animation": "justaudio",
    "audio": "narration.mp3",
    "audioVolume": 0.8,
    "startTime": 0
  }
}

animation: "projection-photo"

Fills all four projection walls with an image between startTime and endTime. Walls turn off when the window ends or the presentation is restarted.

PropertyTypeDefaultDescription
image required string (filename or URL) — Image file in public/data/. JPG, PNG, WebP, GIF, SVG all work. 
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.402, 68.693] },
  "properties": {
    "animation": "projection-photo",
    "image": "overview.jpg",
    "startTime": 10,
    "endTime": 20
  }
}

animation: "projection-video"

Fills all four projection walls with a video, autoplaying immediately with no user controls. The video pauses when the presentation is paused and resumes when it resumes. Walls turn off at endTime or when the presentation is restarted.

PropertyTypeDefaultDescription
video required string (filename) — MP4 file in public/data/. 
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [15.402, 68.693] },
  "properties": {
    "animation": "projection-video",
    "video": "flyover.mp4",
    "startTime": 25,
    "endTime": 45
  }
}

Polygon — areas & zones

Renders a flat filled area at terrain elevation. Supports plain colour, fire particle animation, and 3-D wave animation.

Geometry

{
  "type": "Feature",
  "geometry": {
    "type": "Polygon",
    "coordinates": [[     // outer ring — close it by repeating the first point
      [15.397, 68.687],
      [15.424, 68.688],
      [15.430, 68.700],
      [15.397, 68.687]   // same as first
    ]]
  },
  "properties": { /* see table below */ }
}
Only the exterior ring is rendered. Interior rings (holes) are currently ignored. Coordinate order is [longitude, latitude].

Properties

PropertyTypeDefaultDescription
title optional string — Billboard label shown above the polygon centroid.
color optional hex string #87cefb Fill colour when no animation is set. For wave, this also sets the water colour — use a blue tone. Ignored for fire.
opacity optional integer 0–100 70 Transparency of the polygon (plain colour only). 100 = fully opaque, 0 = fully transparent.
animation optional "fire" | "wave" — fire — dense particle effect covering the polygon footprint at terrain level. The flat polygon is hidden; particles are the entire visual.
wave — animated 3-D wave mesh (sine-wave vertex displacement). Use a blue color for a sea-water look. The flat polygon is hidden.
Both animations work in regular files (always on) and in playback files (use startTime/endTime to show/hide them during a presentation).
startTime optional number (seconds) 0 Seconds after Play when the polygon (or its animation) appears. Playback files only.
endTime optional number (seconds) — Seconds after Play when the polygon (or its animation) vanishes. Playback files only.

Examples

// Plain semi-transparent zone
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Protected area",
    "color": "#44cc88",
    "opacity": 50
  }
}

// Fire animation
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Fire zone",
    "animation": "fire"
  }
}

// Wave / water animation
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Fjord area",
    "color": "#005fad",
    "animation": "wave"
  }
}

LineString — routes, borders & walls

Renders as a ribbon following the terrain. Thin lines stay flat on the surface; tall lines automatically become vertical walls. A label appears at the midpoint.

Geometry

{
  "type": "Feature",
  "geometry": {
    "type": "LineString",
    "coordinates": [   // list of [longitude, latitude] pairs
      [15.388, 68.690],
      [15.405, 68.696],
      [15.445, 68.708]
    ]
  },
  "properties": { /* see table below */ }
}

Properties

PropertyTypeDefaultDescription
title optional string — Billboard label at the midpoint of the line.
color optional hex string #ff1a1a Ribbon colour.
linewidth optional number (metres) 3 Width of the ribbon in real-world metres. Used for both flat lines and the wall thickness.
lineheight optional number (metres) 5 Height of the ribbon in metres. When lineheight is more than 3× linewidth / 2, the ribbon is rendered as a vertical wall instead of a flat road-like surface. Use large values (e.g. 30–100) for fence/wall effects.
animation optional "move" — Animates a 3-D GLB model travelling along the LineString path. No ribbon is drawn — the line acts purely as a path. Requires 3dmodel. Works in regular files (autoplays) and in playback files (respects startTime / endTime).
3dmodel optional string (filename) — Required when animation: "move". Filename of a .glb in public/data/.
modelscale optional number (multiplier) 1 Scale multiplier on top of the automatic size-fitting. Only with animation: "move".
modelrotate optional number (degrees) 0 Additional yaw offset added on top of the path-following heading. Clockwise, compass-style. Only with animation: "move".
speed optional number (scene units/sec) 0.1 How fast the model travels along the path. Only with animation: "move".
title optional (move) string — Floating billboard label that follows the moving model. For non-move lines, the label is placed at the path midpoint instead.
color optional (move) hex string #ffffff Colour of the title label on a moving model. Only has an effect when both animation: "move" and title are set.
startTime optional number (seconds) 0 Seconds after Play when the model becomes visible and starts moving. Playback files only.
endTime optional number (seconds) — Seconds after Play when the model is hidden. Playback files only.
ℹ️ Altitude for flying models: add a third coordinate value (metres above sea level) to each position to give a model elevation — e.g. [15.40, 68.69, 500]. Without a third value the model is draped on the terrain surface (ships, cars). With it the model flies at the given altitude (aircraft).

Examples

// Flat road-like route
{
  "type": "Feature",
  "geometry": { "type": "LineString", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Ferry route",
    "color": "#0044ff",
    "linewidth": 8
  }
}

// Vertical wall / fence
{
  "type": "Feature",
  "geometry": { "type": "LineString", "coordinates": [[/* coords */]] },
  "properties": {
    "title": "Zone boundary",
    "color": "#ff9900",
    "linewidth": 2,
    "lineheight": 40
  }
}

// Ship following a surface route (playback file)
{
  "type": "Feature",
  "geometry": {
    "type": "LineString",
    "coordinates": [
      [15.447, 68.662],
      [15.437, 68.694],
      [15.415, 68.752]
    ]
  },
  "properties": {
    "animation": "move",
    "3dmodel": "ship.glb",
    "modelscale": 1,
    "modelrotate": 0,
    "speed": 0.1,
    "startTime": 0,
    "endTime": 60
  }
}

// Airplane following an elevated route — third coordinate is altitude in metres
{
  "type": "Feature",
  "geometry": {
    "type": "LineString",
    "coordinates": [
      [15.280, 68.655, 400],
      [15.400, 68.695, 480],
      [15.530, 68.730, 550]
    ]
  },
  "properties": {
    "animation": "move",
    "3dmodel": "airplane.glb",
    "speed": 0.3,
    "startTime": 5,
    "endTime": 60
  }
}

PropertyApplies toType & values
title All Any string
color All Hex colour, e.g. "#ff4400"
information Point String — enables click interaction
image Point, projection-photo Filename or URL
video Point, projection-video MP4 filename in public/data/
3dmodel Point, LineString (move) Filename of a .glb in public/data/
modelscale Point, LineString (move) Number multiplier, default 1
modelrotate Point, LineString (move) Degrees clockwise (compass), default 0
opacity Polygon Integer 0–100 (default 70)
animation Polygon only "fire" (particle effect) or "wave" (animated water mesh). Both support startTime/endTime in playback files.
linewidth LineString Metres, default 3
lineheight LineString Metres, default 5. >3× half-width → vertical wall
animation: "move" LineString 3-D model travels the path. Requires 3dmodel.
speed LineString (move) Scene units/sec, default 0.1
startTime Any feature (playback file) Seconds after Play when the feature appears, default 0. Playback files only.
endTime Any feature (playback file) Seconds after Play when the feature vanishes. Playback files only.
animation: "justaudio" Point (playback) Plays audio file at startTime.
audio Point (justaudio) MP3/WAV/OGG filename in public/data/
audioVolume Point (justaudio) 0.0–1.0, default 1.0
animation: "projection-photo" Point (playback) Fills all 4 walls with image between startTime and endTime.
animation: "projection-video" Point (playback) Fills all 4 walls with autoplaying video. Pauses/resumes with the controller.
